Edycja fanowska pełnej wersji gry **Kubuś i Wehikuł Czasu** (11 poziomów) dla Windowsa 10 i 11.

### Do pobrania

| Plik | Dla kogo |
|---|---|
| `Kubus-i-Wehikul-Czasu-…-instalator.exe` | **Polecany.** Instaluje grę, skróty w Menu Start i na pulpicie oraz (opcjonalnie) Adobe Shockwave Player 12. |
| `Kubus-i-Wehikul-Czasu-….zip` | Wersja przenośna: rozpakuj gdziekolwiek i uruchom `Kubus.exe`. |

Archiwa **Source code** GitHub dodaje do każdego wydania automatycznie – to kod źródłowy
projektu (całe repozytorium, ok. 300 MB), a nie gra do zainstalowania. Do grania ich nie potrzebujesz.

Pliki nie są podpisane cyfrowo, więc Windows SmartScreen może ostrzec przed nieznanym programem – kliknij „Więcej informacji” → „Uruchom mimo to”.

Szczegóły, sterowanie i rozwiązywanie problemów: [README](https://github.com/Hayyarden/Kubus-i-Wehikul-Czasu-Edycja-fanowska#readme).
